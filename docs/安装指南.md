# 因果记忆 — 安装指南

## 环境要求

- Python 3.10+
- OpenClaw（或任何 Agent 系统）
- SiliconFlow API Key（用于向量嵌入，可选）

## 快速安装

```bash
# 克隆仓库
git clone https://github.com/MaiHHConnect/MHH-Causality-Memory.git
cd MHH-Causality-Memory

# 一键初始化
bash scripts/setup.sh
```

## 手动安装

### 1. 向量数据库初始化

```bash
cd scripts/gbrain
python3 init.py
```

### 2. 配置 OpenClaw memory_search

在 `openclaw.json` 中添加 gbrain 路径：

```json
{
  "memory": {
    "search": {
      "provider": "custom",
      "script": "/path/to/MHH-Causality-Memory/scripts/gbrain/search.py"
    }
  }
}
```

### 3. Wiki 结构

Wiki 四层目录已包含模板文件：

```
wiki/main/
├── events/           ← 事件层模板（直接使用或复制）
├── timeline/         ← 时间线层（按年/月/周自动生成）
├── relationships/    ← 关系链层
└── abstracts/       ← 抽象总结层
```

## 使用流程

1. **运行 setup.sh** 初始化环境和目录
2. **配置 OpenClaw** 的 memory_search 指向 `scripts/gbrain/search.py`
3. **判断前召回认知锚**：`/usr/bin/python3 scripts/gbrain/gbrain.py anchor "问题"`
4. **执行追踪接入 R0**：`/usr/bin/python3 scripts/gbrain/gbrain.py beads-capture /path/to/project`
5. **候选记忆沉淀**：`/usr/bin/python3 scripts/gbrain/gbrain.py commit`
6. **Scene/Profile 自动沉淀**：`/usr/bin/python3 scripts/gbrain/gbrain.py auto-classify 80`
7. **回归评测**：`/usr/bin/python3 scripts/gbrain/gbrain.py eval eval/gbrain_eval.jsonl`

当前仓库内置 50 条召回回归用例，覆盖 CausaMem、OpenClaw、Beads、cron、DingTalk、GitHub 和 agent heartbeat 记录。

## Beads 边界

Beads 只作为执行追踪现实源，提供任务状态、依赖关系、审计轨迹。CausaMem 仍是主记忆系统。

推荐先用 `bd init --stealth --quiet` 在项目内启用 Beads，再通过 `beads-capture` 把快照写入 `raw_events`。相同快照会被幂等跳过，不会重复污染 R0。

## Scene/Profile 门禁

OpenClaw 插件开启 `modelGateEnabled=true` 后，`agent_end` 流程会变为：

```text
capture -> extract/import candidates -> gate-candidates -> OpenClaw 主模型判定 -> apply-gates -> commit --approved-only
```

模型只负责语义判定，不能直接写库。CausaMem 会继续做确定性验收：

- evidence 必须逐字来自候选 content
- Profile 置信度必须 `>=0.75`
- 临时状态不能写 Profile
- Profile type/key 必须在白名单内
- 冲突旧 Profile 时标记 `conflict`，不自动覆盖

## 核心脚本说明

| 脚本 | 功能 |
|------|------|
| `search.py` | 向量搜索入口，被 memory_search 调用 |
| `ingest.py` | 批量导入 Wiki 内容到向量库 |
| `init.py` | 初始化 SQLite + 向量数据库 |
| `stats.py` | 查看向量库状态 |
| `setup.sh` | 一键初始化脚本 |
| `gbrain.py anchor` | 输出 CausaMem 认知锚定块 |
| `gbrain.py beads-capture` | 读取 Beads 执行状态并写入 R0 |
| `gbrain.py auto-classify` | 自动沉淀 Scene/Profile |
| `gbrain.py gate-candidates` | 输出待门禁候选，供 OpenClaw 主模型判定 |
| `gbrain.py apply-gates` | 应用模型 JSON 判定并执行确定性门禁 |
| `gbrain.py eval` | 运行召回回归评测 |
